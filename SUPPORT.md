# Getting help

- **Questions and ideas**: [GitHub Discussions](https://github.com/musbabaff/travertine/discussions).
- **Bugs**: open an issue with the **Bug report** form.
- **Feature requests**: open an issue with the **Feature request** form.
- **API or data contract changes**: use the **Contract change** form.
- **Security problems**: never in public; see [`SECURITY.md`](SECURITY.md).

The methodology, data sources, model card and validation are documented in [`docs/`](docs).
